# Forwarding emails for each phone company (copy, fill in the [brackets], send)

IMPORTANT: carrier codes and menus change and differ by plan. Dial codes below are the common ones, not guaranteed. Before you send any of these to a customer, try the same steps on your own phone line (on your own carrier) with the Retell number, so you know it works. If a code does nothing, use the phone's settings menu or the carrier's app instead, and call the carrier if needed.

Decide first which way the customer wants it (their setup form, question 3):
- BACKUP (staff answer first; the AI takes calls they miss or after hours): use the "missed calls" steps.
- EVERY CALL (AI answers all): use the "every call" steps.

Always tell them: forwarding only changes where calls go. Their number, website and Google listing do not change, and they can switch it off in seconds.

## 4. iPhone settings (any carrier) and Android settings

Use this when the codes do not work, or the owner prefers menus.

iPhone: Settings, then Phone, then Call Forwarding. This switch forwards EVERY call. It cannot do "missed calls only". For missed calls only, use the carrier codes or carrier app above.

Android: Phone app, then the three dots, then Settings, then Supplementary services (or Calls), then Call forwarding. You usually get four choices: Always forward, Forward when busy, Forward when unanswered, Forward when unreachable. For "missed calls only", set unanswered, busy and unreachable to [number] and leave Always forward off. For "every call", set Always forward to [number].

Suggested wording:

Subject: Switching on your receptionist from the phone settings

Hi [name],

Here is how to do it from your phone's menu: [iPhone steps or Android steps above]. The number to enter is [number]. To turn it off, switch the same setting off. Call or text me if you get stuck, and I can stay on the line while you do it.

[your name]

## When something does not work
- Call goes to normal voicemail instead of the receptionist: the code did not take. Redo it and listen for the confirmation. Try the carrier app or menu.
- Receptionist answers the first ring even for "missed calls": they probably set "every call". Turn it off and redo it as missed calls.
- A forwarded call plays "number not in service": check the digits in [number] (it must be the Retell number with area code), and that the number is attached to their agent in Retell.
- More fixes: docs/forwarding-troubleshooting.md.
